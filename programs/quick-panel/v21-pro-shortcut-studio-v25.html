Contexts & Sources

Context는 언제 동작하는지, Source는 어디에 구현되어 있는지를 정의합니다.

Add context

Context는 “어디서 동작하는가”입니다. AutoHotkey / Tampermonkey는 Context가 아니라 Sources에 등록하세요.

기본은 Global입니다. 필요하면 기존 Context를 Parent로 선택해 예: Illustrator → Photoshop → Global처럼 단계적으로 상속할 수 있습니다.

Add source

Source는 실제 구현 파일이나 시스템을 가리킵니다.

Duplicate context

현재 Context를 기반으로 새 Context를 만듭니다.

Bottom modifier keys

How capture works

단일 키뿐 아니라 Alt+F, Ctrl+Shift+1, Win+Space 같은 전체 조합을 기록합니다. 각 Bank의 15개 키는 서로 다른 조합을 가질 수 있습니다.
