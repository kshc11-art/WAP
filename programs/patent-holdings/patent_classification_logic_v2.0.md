## 1. 목적과 산식

지재권 마스터(상세목록)를 입력받아, 각 기준시점의 등록특허를 아래 항목으로 배타적으로 분류한다.
한 특허는 반드시 하나의 분류만 갖는다(중복 활용 시 1건으로 기재).

| 기호 | 항목 | 정의(기초통계자료 작성기준 요지) |
|---|---|---|
| A | 보유특허 | 당해년도에 보유했거나 보유 중인 특허 (양도·기타활용 포함). A = B + F + J |
| B | 활용특허 | B = C + D + E |
| C | 기술실시(누적) | 기술실시 중이거나 실시한 적이 있는 특허 (소멸했어도 산입) |
| D | 당해년도양도 | 당해년도에 양도(유상+무상, 기부채납 포함)한 등록특허 |
| E | 기타활용(누적) | 출자 등 실시·양도 외 방법으로 활용한 특허 |
| F | 활용추진특허 | F = G + H + I |
| G | 5년 이하 특허 | 미활용 등록특허 중 등록 후 만 5년 미경과 |
| H | 마케팅 추진특허 | 기술이전 연계 마케팅 활동 중인 특허 |
| I | 전략보유특허 | 등록 후 만 5년 경과 특허 중 전략적 보유 대상 |
| J | 미활용특허(휴먼특허) | 미활용 등록특허 중 등록 후 만 5년 경과 |
| - | 미보유 | 위 어디에도 해당하지 않음 (미등록·소멸·양도 등) |

파생 지표: 특허활용률 = B/A, 활용추진 비율 = F/A, 미활용 비율 = J/A.
검산: A = C+D+E+G+H+I+J.

## 2. 공통 판정 규칙 (모든 기준시점 동일)

위에서 아래로 순서대로 검사하여 **처음 해당하는 단계에서 분류를 확정**한다.
기준일을 Y년 12월 31일(반기는 6월 30일)이라 한다.

| 단계 | 결과 | 판정 조건 |
|---|---|---|
| 0 | - | 등록번호가 없다 / 등록일자가 없다 / 등록일이 기준일보다 늦다 |
| 1 | D | 메모에 "Y년 기부채납"이 있다 (또는 당해 양도 수동 목록에 있다) |
| 2 | E | 기준일 이전 계약이 있고 계약 세부가 '출자'이다 |
| 3 | C | 기준일 이전 계약(계약연도 ≤ Y)이 하나라도 있다. 단, 상태가 '양도'이면서 계약이 딱 1건이면 그 계약은 양도계약이므로 '-' (계약 2건 이상이면 기술이전 후 양도로 보아 C. 예: P060034KR) |
| 4 | (생존 판정) | 기준일 당시 상태를 **완전생존 / 조건부생존 / 사망** 셋으로 구분한다(3장 8번). 사망이면 '-' |
| 5 | I | 전략보유 대상(시점별 근거)이고 등록 후 만 5년 경과 |
| 6 | H | 마케팅 대상(시점별 근거)이다 |
| 7 | G | 등록 후 만 5년 미경과 |
| 8 | J 또는 - | 위 모두 해당 없음(만 5년 경과 + 미활용). **완전생존이면 J, 조건부생존이면 '-'**(계상 명분 소멸) |

우선순위가 곧 규칙이다.
- 활용(C·D·E)이 활용추진(G·H·I)보다 앞선다: 기술이전 이력이 있으면 마케팅 대상이어도 C.
- 전략보유(I)가 마케팅(H)보다 앞선다. 마케팅(H)이 5년 이하(G)보다 앞선다.
- 전략보유 대상이라도 만 5년 미경과이면 I가 아니라 H 또는 G로 내려간다.

## 3. 핵심 정의와 경계

1. **기준일 포함**: 등록일 = 기준일 당일 건은 포함한다. (예: 2026-06-30 등록 P230144US는 2026 상반기 산입)
2. **만 5년 경계**: 등록일 ≤ (기준일 − 5년)이면 '5년 경과'. 연말 기준에서는 등록년도 필터와 결과가 같고(예: 2025년말 → 등록년도 2021~2025 = 5년 이하), 반기에서만 달라진다(2026. 6. 30. 기준 → 2021. 7. 1. 이후 등록 = 5년 이하).
3. **계약연도**: 계약번호 앞 4자리(YYYY#####)가 계약 체결연도이다. 콤마로 여러 건이 기재될 수 있다. '필드값 없음'은 계약 없음으로 본다. 이 방식으로 과거 시점의 C·E를 소급 산출한다.
   - 계약번호 열의 위치는 파일 종류마다 다르므로(원본 마스터 67열: BJ / 특허분류 삽입본 68열: BK / 25결산본 69열: BL) **열 문자가 아니라 열 이름으로 찾는다.** 스크립트도 열 이름·위치 매핑과 값 형식 검증(YYYY##### 적합률 100%)으로 처리하며, 초기 실무 메모의 "BO열" 표기는 사용하지 않았다.
4. **기부채납 = 양도(무상)**: 메모의 "YYYY년 기부채납" 연도가 양도 연도이다.
5. **D 우선(당해년도)**: 당해년도에 양도된 특허는 기술이전 이력이 있어도 D로 계상한다(2025년 제출 기준). 전년도 이전에 양도된 특허는 기술이전 이력이 있으면 C, 없으면 '-'.
6. **양도 + 계약 1건 = 제외**: 그 계약이 양도계약이라는 전제이다. 계약이 실시계약이고 양도가 별도였음이 확인되면 C로 정정한다(6장 미해결 ② 참고).
7. **상태 세부가 빈칸**: 등록·유지와 동일하게 생존으로 본다(실무상 대부분 계약 보유 건).
8. **생존의 3구분** (2025년 결산 확정값 전수 검증으로 도출한 규칙)

   | 구분 | 해당 상태 | 처리 |
   |---|---|---|
   | 완전생존 | 등록, 유지, 빈칸 | I·H·G·J 모두 계상 |
   | 조건부생존 | 연차포기, 등록취소 | **I·H·G 명분이 있을 때만 계상**, J로 떨어지면 제외 |
   | 사망 | 양도, 기부채납, 존속만료, 등록포기, 출원 관련 상태 등 | 계상하지 않음(플래그가 있어도 제외) |

   취지: 연차포기·등록취소는 권리가 즉시 소멸하지 않고 정리 중인 상태이므로, 마케팅 중이거나 전략 관리 대상이거나 등록 5년 이내이면 관리 실익이 있어 계상한다. 반대로 양도·기부채납은 소유권이 이전되었고 존속만료는 권리 자체가 소멸하여 계상하지 않는다.

   검증(2025년 확정값, 예외 0건): 연차포기·등록취소 1,433건 중 마케팅Y 13건 → 전건 H, 전략Y·5년경과 5건 → 전건 I, 무플래그·5년이내 6건 → 전건 G, 나머지 1,409건 → 전건 제외. 양도·기부채납·존속만료 중 플래그 보유 1건(P160104KR) → 제외.

## 4. 연도 전환 규칙 (세 가지)

1. **전년도 양도 제외**: Y년에 양도(기부채납)된 특허는 Y년에는 D, (Y+1)년부터는 보유에서 제외한다. (기술이전 이력 있으면 C로 잔존)
2. **포기결정 배치**: Y년 상반기 조사에서 포기 결정된 특허는 실제 소멸이 다음 해이므로, **Y년 반기(6. 30.) 기준에는 포함**하고 **Y년 12월 31일 기준부터 제외**한다. 거꾸로 (Y−1)년 12월 31일 기준에서는 생존으로 소급한다. (예: 2024년 배치 = 처분목록 불납지시 120건, 2025년 배치 = 이른바 128건)
3. **지속 계상의 명분 소멸 시 제외**: 결산에서 소멸 상태임에도 수기 계상했던 특허는, 이후 시점에 마케팅·전략·5년 이하 어느 명분도 남지 않고 미활용(J)으로만 분류되는 순간 제외한다. (2026 상반기에서 P190087KR 등 3건 제외 처리)

## 6. 전 시점 동일 로직 여부

- 판정 규칙(2장)·정의(3장)·연도 전환 규칙(4장)은 **다섯 시점 모두 완전히 동일**하다. 2025년에 별도의 수기 조정을 하지 않는다.
- 시점마다 달라지는 것은 규칙에 넣는 **입력 자료의 시점**뿐이다(5장). 각 시점은 그 시점의 상태·플래그를 쓴다. 2023·2024년은 24년말 스냅샷, 2025년은 결산 시점 자료, 2026년은 현재 마스터를 사용한다.
- 검증: 2025년을 결산 확정값 채택 없이 공통 규칙만으로 산출한 결과 **4,393건 전건이 확정값과 일치**한다(개별 예외 3건 지정 후 불일치 0건).
- 이전 문서(v1.1)에서 "확정값에 규칙으로 도출되지 않는 담당자 판단 27건이 포함된다"고 기술한 부분은 **오류이므로 철회한다.** 재검증 결과 27건 중 24건은 위 조건부 생존 규칙과 데이터 시점 차이로 설명되며, 실제 개별 예외는 아래 3건뿐이다.

|---|---|---|---|
| P240064JP | - | 5년 이하 특허 | '25. 11. 등록·생존이나 결산에서 제외. 사유 미확인 |
| P200058EU | - | 마케팅 추진특허 | '25. 12. 등록·마케팅Y이나 결산에서 제외. EP 국가검증 중복 방지 추정 |

## 8. 작성기준 원문 대비표 (항목별 반영 검증)

| 원문 항목 | 원문 요지 | 반영 방식 | 판정 |
|---|---|---|---|
| 보유특허(A) | 당해년도에 보유했거나 보유 중(양도·기타활용 포함) | A = B+F+J. 당해 양도(D)·기타활용(E)·소멸-기술이전(C) 포함 | 반영. 단 문언을 엄격히 읽으면 연중 소멸한 '미활용' 건도 포함될 수 있으나, 기관 관행(전 연도 제출 일관)은 연말 생존 + 활용이력 잔존 기준이며 본 산출물은 관행을 따름(주석 ①) |
| 기술실시(누적)(C) | 실시 중이거나 실시한 적이 있는 특허 | 계약연도 ≤ 기준연도인 실시계약 보유 전건. 연차포기·존속만료·기부채납 상태여도 산입 | 반영 |
| 당해년도 양도(D) | 당해년도 양도(유상+무상) 등록특허 | 무상(기부채납)은 메모 연도로 자동, 유상은 수동 목록(DONATE_MANUAL) | 반영. 유상양도는 마스터에 식별 필드가 없어 수동 입력 필요(주석 ②) |
| 기타활용(누적)(E) | 출자 등으로 이전 | 계약세부 '출자' + 계약연도 소급(2022 알리오 14건 일치 검증) | 반영 |
| 중복 활용 1건 | 1개 특허 중복 활용 시 1건 | 단계 순서에 따른 배타 분류(D>E>C>추진>미활용) + 검산 A=ΣC..J | 반영 |
| 활용추진특허(F) | "등록 후 5년 미경과" | 조사표 구조(F=G+H+I)를 따름. H는 연령 무관, I는 5년 경과이므로 원문 문언과 조사표 구조가 불일치하며 본 산출물은 조사표 구조 우선(주석 ③) | 반영(구조 기준) |
| 마케팅 추진특허(H) | 기술이전 연계 마케팅 활동 중 | 마스터 마케팅 플래그(시점별 근거). 기술이전·전략보유 우선순위 적용 | 반영. 소멸 상태의 마케팅 계상은 수기 판단 영역(6장 22건) |
| 전략보유특허(I) | 5년 경과 + 패밀리·**공동출원**·표준·법규제한 등, 미활용에서 제외 | 5년 경과 요건 + 플래그/진단 S·A등급. 미경과 시 H·G로 하향. 공동출원 제외 규칙은 해제(원문상 공동출원은 포함 사유) | 반영 |
| 미활용특허(원문 G, 조사표 J) | 미활용 + 5년 경과 | 단계 8. 원문과 조사표의 기호 차이(G/J)는 표기 문제일 뿐 정의 동일 | 반영 |

주석 ① A 문언 vs 관행: 존속만료·연차포기 등 연중 소멸 미활용 건은 미산입(전 연도 제출본과 동일한 처리).
주석 ② 유상양도 사례: 2022년 알리오 양도 1건 확인 — 기초통계 D 산입 여부는 당해 승인 공문으로 확정 필요.
주석 ③ F 문언 불일치는 기초통계 양식 자체의 문제로, 모든 연도 제출본이 조사표 구조(F=G+H+I)를 따르고 있음.
