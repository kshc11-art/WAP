# KRISS Committee Automation v0.2.9

## 핵심 원칙

입력 XLSX는 **2개만** 사용합니다.

1. `지식재산권 상세목록.xlsx`
2. `MarkPro 회신.xlsx`

MASTER는 Python/XlsxWriter로 생성합니다. GUI의 HWP 단계는 **현재 입력 → MASTER → 내장 위원회 HWP 템플릿**을 자동 연계하며, CLI/배치는 기존처럼 MASTER + 템플릿(폴더 또는 ZIP)을 직접 지정할 수 있습니다.

## v0.2.6 — Windows 배치 규칙 고정 + 한/글 표 자동화 강화

이번 버전은 Windows 실행 안정성과 한/글 표 서식을 함께 손봤습니다.

### Windows BAT/CMD 규칙

배포본의 모든 `.bat`/`.cmd`는 다음 규칙을 릴리스 검사에서 강제합니다.

- 파일명/내용 ASCII만 사용
- BOM 없음
- CRLF 전용, bare LF 0
- `chcp` 사용 금지
- 한글 `echo`/주석 및 스마트 따옴표/emoji 없음
- `cd /d "%~dp0"` 사용
- 경로는 항상 따옴표 처리
- `activate.bat`에 의존하지 않음
- `.venv\Scripts\python.exe` / `pythonw.exe` 직접 호출
- 로컬 스크립트/배치 호출 대상이 실제 배포본에 존재하는지 검사

`tools/validate_release.py`가 위 항목을 자동 검사하며 `validate_release.bat`로도 실행할 수 있습니다.

### 버전별 venv 재설치 방지

실제 Python 환경은 `%LOCALAPPDATA%\KRISS_Committee_Automation\.venv`에 두고 모든 릴리스가 공유합니다. v0.2.2~v0.2.5의 `%LOCALAPPDATA%\KRISS_Committee_Automation\runtime\venv`가 이미 있으면 최초 v0.2.6 실행 시 짧은 AppData 경로의 `.venv`가 기존 환경을 가리키도록 연결해서 재사용합니다.

BAT는 `activate.bat` 없이 다음 실행파일을 직접 호출합니다.

```text
%LOCALAPPDATA%\KRISS_Committee_Automation\.venv\Scripts\python.exe
%LOCALAPPDATA%\KRISS_Committee_Automation\.venv\Scripts\pythonw.exe
```

프로그램을 공백·한글·긴 경로에 설치해도 Python 실행파일 자체는 짧은 AppData 경로에 있으므로 릴리스 경로 길이에 덜 민감합니다. `requirements.txt`가 바뀐 경우에만 공용 환경의 필요한 패키지를 갱신합니다.

### 한/글 연결과 표 처리

제공받은 `한글편집단축키.py`의 검증된 자동화 패턴을 반영했습니다.

- 연결: `pyhwpx → EnsureDispatch → dynamic.Dispatch`
- `EnsureDispatch`의 `gen_py` 캐시 손상 시 1회 복구 후 재시도
- `FilePathCheckerModule` 보안 모듈 레지스트리 등록 보조
- 액션 실행: `CreateAction → CreateSet → GetDefault → SetItem → Execute`
- 표 위치/블록 선택: `TableCellBlock`, `TableCellBlockRow`, `TableCellBlockExtend` 계열 사용
- `CellBorderFill`/머리행 서식 코드는 제공 파일의 액션 순서를 그대로 참고한 **검증·보조 helper**로 포함
- 실제 위원회 HWP 생성에서는 기존 템플릿의 테두리·배경·문단·글자 스타일 ID를 강제로 덮어쓰지 않고 원본 행 서식을 상속
- 이유: 같은 모양을 다시 적용해도 한/글이 새 스타일 ID를 만들 수 있어 원본 동일성 검증을 오히려 깨뜨릴 수 있으므로, 기본 경로는 템플릿 보존을 우선

기존 v0.2.5의 **첫/마지막 데이터행 보존, 원본 병합만 재적용, 저장 후 HWP 바이너리 표서식 감사**도 유지합니다. Windows에서 실제 SaveAs 결과의 폭·여백·테두리/배경·문단/글자모양·병합구조가 원본과 달라지면 성공 처리하지 않습니다.

검증 도구:

- `tools/validate_plan.py` — 데이터 매핑 골든 회귀
- `tools/validate_hwp_style.py` — 내장 HWP 6종 구조/스타일 파서 회귀
- `tools/validate_hwp_reference_style.py` — 제공 코드 기준 CellBorderFill/머리행 서식 액션 회귀
- `tools/validate_release.py` — BAT/CMD 규칙 검사
- `tools/validate_path_handling.py` — 공백/한글/260자 초과 릴리스 경로 + 공용 `.venv` 별칭 smoke test

> Linux 개발환경에서는 한컴오피스의 실제 화면 렌더링을 실행할 수 없습니다. Windows에서 SaveAs한 결과 HWP 자체에 대한 자동 스타일 감사는 실행되며, 페이지 나눔·긴 문구 줄바꿈·그림 위치는 실제 한/글에서 최종 육안 확인 대상입니다.

### HWP 생성

메인 GUI의 **`한글 안건 만들기`** 는 이제 파일 선택창 없이 한 번에 동작합니다.

- 현재 입력/분기/그래프 설정과 일치하는 MASTER가 이미 있으면 즉시 재사용
- MASTER가 없거나 입력·설정이 바뀌었으면 MASTER를 먼저 자동 재생성
- 선택한 위원회 연도/회차에 맞는 **내장 HWP 양식팩 또는 사용자 공용 양식폴더**를 자동 사용
- HWP 출력은 MASTER 폴더의 `hwp_output`에 자동 저장
- MASTER/템플릿/출력폴더 선택 대화상자는 띄우지 않음
- 그래프 ZIP 등 **.hwp가 없는 ZIP은 템플릿 후보에서 제외**

배포본에는 제공받은 **2026년 제1차 양식 6종**을 `resources/hwp_templates/2026_1/`에 실제 `.hwp` 파일로 내장했습니다. 따라서 별도 복사 없이 바로 동작합니다. 향후 다른 회차 양식은 GUI 하단의 **`한글양식 폴더`** 버튼을 누르면 `%LOCALAPPDATA%\KRISS_Committee_Automation\templates\<연도>_<회차>`가 즉시 열리며, 그곳에 HWP 6종을 넣으면 자동 인식합니다. 이 폴더는 프로그램 버전을 교체해도 유지됩니다.

배치에서는 MASTER/템플릿/출력폴더 3개 경로를 전달할 수 있습니다. 템플릿 ZIP도 지원하지만 GUI의 자동 내장양식 사용을 권장합니다.

```bat
fill_hwp_windows.bat "MASTER.xlsx" "committee_templates.zip" "output\hwp"
```

고급 옵션이 필요하면 GUI를 사용하거나 `%LOCALAPPDATA%\KRISS_Committee_Automation\.venv\Scripts\python.exe`로 `hwp_fill.py`를 직접 실행합니다. 주요 옵션:

- `--dry-run` : 한/글을 열지 않고 `fill_plan.json`, `preview_*.txt`, `template_preflight.txt`까지만 생성
- `--date 2026-04-13` : 보고/심의일자를 명시. 생략하면 템플릿에서 유효 날짜를 추론하며, 제공된 2026년 1차 양식은 붙임1의 `2026-04-13`을 자동 인식
- `--dept-map map.csv` : 붙임5 `본부(소)` 매핑을 별도 지정. 생략 시 `config/dept_map_<연도>_<회차>.csv` 자동 사용
- `--docs b1,b2,b5,b6,b7,b8` : 생성 문서 선택. 기본은 6종 전체
- 회차/연도는 MASTER `00_요약`의 `위원회` 값을 우선 사용하고, 구버전 MASTER에 해당 값이 없을 때만 기준분기로 fallback
- `--allow-annex-mismatch` : 붙임5 별첨과 MASTER가 달라도 강제 진행. **정합성 위험 때문에 기본값은 차단**

### 자동화 범위

- **붙임1** 출원 보고: 표지/본문 문구, 국내·국외 표, 통계표, 그래프
- **붙임2** 등록 보고: 표지/본문 문구, 국내·국외 표, 통계표, 그래프
- **붙임5** 국외출원 심의: 본부별 집계, 심의목록, 본부 매핑, 기존 별첨 14세트 연계검증 후 보존
- **붙임6** 특허 포기: 주문/제안 문구, 절차 현황, 국내·국외 표
- **붙임7** 개최 운영(안): 작성월 및 안건명 자동 갱신. 위원 명단·예산은 템플릿 값 유지
- **붙임8** 서면결의서: 작성월·안건명·결의일 갱신. 위원 표시/의견/서명란은 빈 양식 유지

제공 템플릿의 표 구조는 HWP 바이너리의 행/열/셀 병합 정보를 Windows 실행 전에 사전검사합니다. v0.2.6에서는 기존 병합을 `TableSplitCell`로 먼저 정규화하고, **첫/마지막 데이터행의 원본 서식을 남긴 채 중간행만 증감**합니다. 세로병합은 원본 템플릿에 실제 병합이 있던 표에만 MASTER 그룹 기준으로 다시 적용합니다. 예상하지 못한 열 수나 데이터 영역 병합은 조용히 덮어쓰지 않고 차단합니다. 저장 후에는 생성 HWP의 표 폭·여백·테두리/배경·문단/글자모양·병합구조를 원본과 다시 비교합니다.

### 2026년 제1차 과거 정본 재생성 경고

현재 원천 데이터로 과거 회차를 다시 만들면 사후 등록/출원번호 부여 등으로 당시 정본과 달라질 수 있습니다. v0.2.3은 2026년 제1차에 대해 보관 골든과 식별자를 비교하여 `template_preflight.txt`에 **데이터 드리프트 경고**를 남깁니다.

2026-08-19 상세목록으로 만든 현재 MASTER에서는:

- 등록: 정본 45건 → 현재 46건 (`12566224` 추가)
- 국외심의: 당시 `(출원전)` 1건이 현재 `19/638249`로 변경
- 붙임5 개별 평가표 중 조경민 건의 현재 발명명칭이 당시 별첨과 달라 기본 preflight에서 붙임5 생성 차단

즉, **현재 MASTER의 값을 따르는 것**과 **2026년 1차 당시 정본을 복원하는 것**을 구분합니다.

### 검증/종료코드

적용 중 표 셀을 다시 읽어 계획값과 대조하고, 저장 후에는 생성된 HWP를 바이너리 수준에서 다시 읽어 표 디자인 핵심속성을 원본과 비교합니다. `hwp_fill_report.txt`에 값 검증과 `[서식검증]` 결과를 함께 남기며 허위 “완료”를 표시하지 않습니다.

- `0`: 자동 생성 및 검증 완료
- `1`: preflight 또는 HWP 적용 실패

## v0.1.7 이후 유지되는 핵심 원칙

### 1) 안건 기준분기와 포기특허 기준분기 분리

출원·등록·국외출원 심의는 GUI에서 선택한 **안건 기준분기**를 사용합니다.

포기특허는 업무상 그보다 **1분기 뒤의 보고 기준분기**를 사용하므로 GUI와 MASTER에 별도로 표시합니다.

예:

- 안건 기준: `2026년 2분기`
- 포기특허 기준: `2026년 3분기 (+1분기)`

중요: 포기특허 대상 자체는 `MarkPro 회신`의 `납부구분`에 `포기`가 포함된 건을 원천으로 사용합니다. `납부여부=N`은 참고값일 뿐 대상 판정 조건으로 사용하지 않습니다. **+1분기 날짜필터도 추가로 적용하지 않습니다.** 기준분기는 위원회 문서상 기간 메타데이터입니다.

`13_포기심의`에는 `안건 기준분기`, `포기 기준분기` 열을 함께 기록합니다.

### 2) 국외출원 심의 자동 판정

`12_국외심의`를 지식재산권 상세목록에서 직접 만듭니다.

- 특허만 대상
- 국내 제외
- `지재권신청일`이 위원회 대상기간 안에 있는 건
- `신청 취소` 제외
- `유럽건 재등록` 제외
- 일반 국외출원은 같은 `패밀리번호`에 과거 PCT가 있으면 제외
- PCT 또는 PCT 이력이 없는 최초 국외출원은 심의대상

2026년 1차 검증자료에서 기존 RAWDATA의 **14건과 14/14 일치**했습니다.

1차 위원회에서 전년도 Q4 + 당해 Q1을 선택하면 확인된 과거 경계값을 재현하기 위해 Q4 시작 직전 1일도 국외심의 신청일 범위에 포함합니다. 2026년 1차의 경우 `2025-09-30 ~ 2026-03-31`입니다.

### 3) 빈 MASTER 방지

v0.1.4의 Excel COM 2차원 배열 쓰기 방식을 사용하지 않습니다.

MASTER는 Python에서 직접 XLSX로 생성하며, 저장 후 프로그램이 다시 열어 다음을 검사합니다.

- 필수 시트 존재 여부
- `00_요약` 실제 문자열
- 출원/등록/국외심의/포기 요약 건수
- RAW 상세목록/MarkPro 실제 행 수
- 출원/국외심의/포기 시트 실제 데이터 행 수
- `13_포기심의`의 포기 기준분기 값
- **시트 순서 일치 여부**
- **`20_그래프데이터` 전체 기간 보존 여부**
- **그래프 표시기간이 데이터 범위 안에 있는지 여부**
- 비정상적으로 작은 파일 여부

검증 실패 시 완료 메시지를 띄우지 않습니다.

### 4) GUI

- 기본 화면은 **스크롤 없이 한 화면에 표시**되는 compact 레이아웃
- 지식재산권 상세목록/MarkPro 파일 표시 영역은 한 줄형 소형 카드로 표시
- XLSX 파일 또는 폴더는 **창 어디에 드롭해도** 자동 인식
- 하단 생성 버튼 고정
- 안건 기준분기와 포기특허 기준분기를 동시에 표시
- 포기 지표에도 `+1분기 / MarkPro 원천` 표시
- 회차 기본분기 자동 선택
  - 1차: 전년도 Q4 + 당해 Q1 → 포기 기준 Q2
  - 2차: 당해 Q2 → 포기 기준 Q3
  - 3차: 당해 Q3 → 포기 기준 Q4
  - 4차: 당해 Q4 → 포기 기준 다음 연도 Q1

### 5) 그래프 (v0.2.3)

별도 그래프 XLSX 없이 상세목록을 직접 집계합니다. 색상은 v0.1.4 기준을 사용합니다.

#### 형태

GUI `고급 설정`에서 두 디자인 중 하나를 선택합니다. 기본값은 **꺾은선형**입니다.

| 형태 | 구성 | 최근연도 숫자 |
|---|---|---|
| 꺾은선형 (기본) | 국내 / 국외(PCT) / 전체 3개 선 | 전체는 위쪽 배지, 국내는 좌측, 국외는 우측으로 분리 |
| 막대+꺾은선형 | 국내/국외 누적 막대 + 전체 추이선 | 막대 구성값은 내부, 전체는 위쪽 배지 |

공통 디자인:

- 국내 `#375B7C`, 국외 `#6991AE`, 전체 `#2D2D2D`
- 최근연도는 옅은 배경으로 강조
- 그래프 내부의 설명성 부제 문구 제거
- 상단 범례, 옅은 가로 격자, 최소 테두리
- 숫자는 최근연도에만 표시
- MASTER `30_그래프` / 일반 PNG / HWP 삽입용 PNG를 동일한 형태로 생성

CLI에서는 `--graph-style line|combo`로 지정할 수 있습니다.

#### 표시기간

기본값은 **최근 10년**입니다. GUI의 `고급 설정`에서 변경할 수 있습니다.

- `최근 5년`
- `최근 10년` (기본)
- `전체`
- `직접지정` → `시작년도` / `종료년도` 입력

CLI에서는 다음과 같이 지정합니다.

```
--graph-range recent5|recent10|all|custom
--graph-start-year 2019 --graph-end-year 2023
```

지정 범위가 데이터 범위를 벗어나면 자동으로 데이터 범위 안으로 보정합니다.

> **중요**
> 표시기간은 `30_그래프`와 PNG에만 적용됩니다.
> MASTER의 `20_그래프데이터`는 표시기간과 무관하게 **전체 기간(2013~기준연도)** 을 그대로 유지합니다.
> 어느 연도가 차트에 표시되는지는 `차트표시` 열로 확인할 수 있습니다.

#### 산출 파일

| 파일 | 용도 |
|---|---|
| `application_trend.png` | 출원 추이 · 화면/검토용 (180dpi) |
| `registration_trend.png` | 등록 추이 · 화면/검토용 (180dpi) |
| `application_trend_hwpx.png` | 출원 추이 · **HWPX 삽입용** (약 16cm 폭, 300dpi) |
| `registration_trend_hwpx.png` | 등록 추이 · **HWPX 삽입용** (약 16cm 폭, 300dpi) |

HWPX 삽입용 PNG는 보고서 본문 폭(약 16cm)에 맞춰 글꼴·마커를 축소한 별도 레이아웃입니다. 한글에서 **원본 크기(100%)로 삽입**하면 별도 조정 없이 본문 폭에 맞습니다.

PNG는 Windows에서는 `Malgun Gothic`을 우선 사용하고, 다른 환경에서는 Noto/Nanum 계열 한글 폰트를 자동 탐색합니다.

## 사용 방법

1. `run_windows.bat` 실행 (최초 1회 공용 런타임 자동 준비)
2. 필요하면 `system_doctor.bat`
3. 상세목록 + MarkPro 두 XLSX를 드롭
4. 위원회 연도/회차 확인
5. 필요하면 안건 기준분기 조정
6. 필요하면 `고급 설정`에서 그래프 형태(꺾은선/막대+꺾은선)와 표시기간 변경
7. GUI에 표시되는 `안건 기준` / `포기특허 기준(+1분기)` 확인
8. 미리보기에서 출원 / 등록 / 국외심의 / 포기 건수 확인
9. MASTER만 필요하면 `작업 MASTER 만들기`
10. HWP까지 필요하면 `한글 안건 만들기` — 필요한 경우 MASTER를 자동 생성/재사용한 뒤 HWP까지 연속 실행
11. `hwp_output\hwp_fill_report.txt`에서 값 검증과 `[서식검증]` 결과 확인

## MASTER 시트

실제 생성 순서와 동일합니다. 저장 후 시트 **순서까지** 재검증합니다.

1. `00_요약`
2. `10_출원현황`
3. `11_등록현황`
4. `12_국외심의`
5. `13_포기심의`
6. `20_그래프데이터` — 전체 기간 보존
7. `30_그래프` — 선택한 그래프 형태(꺾은선형 또는 막대+꺾은선형), 표시기간 적용
8. `90_검증`
9. `99_RAW_상세목록` — 행 높이 통일
10. `100_RAW_마크프로` — 행 높이 통일

심의결과 HWP/HWPX의 건별 캡처/이미지 삽입은 다음 HWPX 생성 단계에서 붙이는 구조입니다.
