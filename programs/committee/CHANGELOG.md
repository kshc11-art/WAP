### 표기 규칙 (요청 반영)
- 작은따옴표는 **U+0027(')** 로 통일(’ 포함 기존 표기는 탐색 시 동일 인식, 기입 시 '로 교정)
- 물결은 **∼(U+223C)** 로 통일: 기간·통계 라벨(`2026년(∼6월)`)·MASTER 00_요약, 파서는 ~/∼/～ 모두 인식. 병합본 원본 고정 문구(평가 배점 각주 등)는 양식 보존 원칙에 따라 미변경
- 날짜는 **m-d(선행 0 없음)**: 한글 표 `2026-4-10`, 엑셀 날짜 서식 `yyyy-m-d`, 요약 문자열 동일
- **발명자 콤마 뒤 공백**: `normalize_name_list()`로 MASTER 원천 추출·한글 표(발명자·주발명자)·본부 매핑 키 모두 정규화("홍길동,김철수"→"홍길동, 김철수"). 출원인/권리자(기관명)는 원본 보존
- 값 갱신 판정을 엄격 비교로 분리(`_same`/`same_text`): ’→' 같은 표기 교정이 "기존 값과 동일"로 스킵되지 않도록(anchor 탐색은 종전대로 관대)

## v0.2.8 — 표 생성 오류·그래프 오류 수정 (2차 실행 결과 반영)

### 오류 수정 (표)
- **한/글의 셀 순회는 물리 셀이 아니라 '행×셀'**: 세로병합 셀은 걸친 행마다 다시 방문된다. 붙임1 표6이 물리 77셀인데 80으로 세어져 `예상하지 못한 병합 구조 (총 80셀)`로 건너뛰던 원인. 머리셀 수·병합 위치를 템플릿 바이너리에서 **순회 기준으로 계산**하도록 변경(실제 템플릿 4종 검증)
- **행 삭제/추가 실패**: 축소 경로의 순서 버그(행 선택 전에 캐럿이 표 끝으로 이동) 수정. 액션 이름을 여러 후보로 시도하되 **반환값이 아니라 셀 수 변화로 성공을 판정**하고, 엉뚱하게 바뀌면 Undo. 동작한 액션 이름을 리포트에 기록
- **행 수를 못 바꿔도 표를 건너뛰지 않음**: 담을 수 있는 만큼 채우고 남는 행은 비운 뒤, 미수록/잔여 행 수를 리포트에 남김
- **세로병합은 채우기 전에 분할하고 다시 병합하지 않음**: 실제 산출물(2차)의 데이터 표에 병합이 0곳인 것을 확인해 그 형태에 맞춤

### 오류 수정 (그래프)
- 삽입용 PNG를 **알파 없는 RGB로 저장**(한/글에서 개체만 생기고 그림이 비는 증상 대응)
- 그림 삽입을 **래퍼 뒤의 원본 COM 객체로 호출**하고 호출 형태를 바꿔 가며 개체 증가로 판정, 삽입 후 크기 재적용
- 저장본의 BinData를 확인해 `[그림확인] 저장본에 이미지 N개 포함`을 남기고, 없으면 실패 보고
- 마지막 값 라벨을 **오른쪽 같은 x에 세로 정렬**(검은 상자 제거, 겹침 방지 간격, 오른쪽 여백 확보)

### 동작 변경
- 붙임5 본부(소)는 MASTER에 없는 항목이므로 `-` 대신 **빈 칸**, 경고를 참고로 완화(`--dept-map`으로 채울 수 있음)
- 서식 검증은 **레이아웃(폭·여백·테두리)** 만 실패 기준으로 두고, 글자를 다시 쓰면 새로 배정되는 문단·글자 모양 ID 차이는 제외

### 검증

## v0.2.7 — 한글 삽입 실패 원인 수정 (실측 로그 반영)

2026년 제2차 실행에서 "MASTER는 되는데 한글에 안 들어가는" 문제의 원인을 규명하고 수정.

### 오류 수정
- **셀 읽기(치명)**: 셀 블록 상태의 `GetTextFile("TEXT","saveblock:true")`는 선택 셀이 아니라 **표 전체**를 반환한다. 셀=리스트 범위의 문자 블록(`MoveListBegin`→`MoveSelListEnd`)으로 읽도록 변경. 이로 인해 발생하던 전 표 `[건너뜀] 머리행 불일치`·표지 셀 `[검증실패]` 해소
- 문서를 열 때 셀 읽기 프로브 1회 수행 — 셀 단위 읽기가 불가하면 조용히 넘어가지 않고 즉시 중단
- 셀 쓰기도 셀 내부 문자 블록만 지우고 기입(셀/표 구조 미접촉)
- **문단 교체가 표를 삭제하던 문제**: 붙임2 소제목 문단에는 표 앵커가 같은 문단에 들어 있어 문단 전체 Delete 시 표4가 함께 사라졌다(저장본 표 인덱스가 밀리던 원인). 개체 앵커가 있으면 **개체 뒤 구간만** 교체하고, 표 개수가 줄면 Undo로 되돌린 뒤 실패 보고
- **그림 교체**: 문단을 지우지 않고 그리기 개체만 선택·삭제. 다음 문단에 표가 있으면 중단
- **anchor 반복 탐색**: `RepeatFind`가 문서 끝에서 처음으로 되돌아오는 것을 문단 위치로 감지해 종료(기존 `60곳` 오보고 해소)
- 리포트 진단 축약: 표 전체 덤프 대신 `읽음=… 기대=…` 형태로 출력, 값 검증 실패 시 어느 행·열인지 표시

### 동작 변경
- 붙임5 별첨 개별 평가표 불일치는 기본적으로 **경고 + 수동 과제**로 처리(문서는 생성). 기존처럼 차단하려면 `--strict-annex`. `--allow-annex-mismatch`는 호환용으로 유지

### 검증
- `tools/fake_hwp.py`: 한/글 COM 객체 모형(관측된 오작동 2종 재현)
- `tools/validate_com_logic.py`: v0.2.6 실패 재현 + v0.2.7 수정 확인 — 34/34 통과
- 기존 검증 전부 재실행 통과, 실제 원천 2종으로 MASTER→사전검사 재현(ERROR 0건)
