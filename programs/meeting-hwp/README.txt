경영전략회의 HWP 취합기 v0.4.2
=================================

[버전 변경]
0.4.1 -> 0.4.2

날짜 표기 정규화 누락을 보완한 Patch 버전입니다.

[문제]
v0.4.1은 주로 월/일 형태만 잡았습니다.

09.01. -> 9.1.

하지만 연도가 붙은 전체 날짜는 월 앞의 '.' 때문에 기존 월/일 정규식에서 제외될 수 있었습니다.

예:
2026.09.01. ~ 2027.08.31.

[0.4.2 수정]
연도-월-일 전체 날짜를 먼저 별도 정규식으로 처리합니다.

2026.09.01. -> 2026.9.1.
2027.08.31. -> 2027.8.31.
2027/08/31  -> 2027.8.31.

따라서:
2026.09.01. ~ 2027.08.31.
->
2026.9.1. ~ 2027.8.31.

연도가 없는 날짜도 계속 처리합니다.

09.01. -> 9.1.
08/25(화) -> 8.25.(화)

[예외 유지]
날짜가 아닌 값은 계속 건드리지 않습니다.

1.8%    -> 그대로
4.3년   -> 그대로
0.05 μmol -> 그대로

[보존 우선 구조 유지]
- HWP 셀 내용은 원본 Copy/Paste
- 표/볼드/글꼴 보존
- 자동 중복 삭제 없음
- 빈 문단 정규화
- 8개 독립 셀
- 보안모듈
- 비동기 실행/중지/타임아웃
