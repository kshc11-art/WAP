# scripts/_shared/

여러 스크립트에 공통으로 들어가는 코드의 **원본**이다. 여기 있는 것을 봇이 각 스크립트 파일 안에
복제해 넣는다. 빌드가 아니라 복제인 이유: **사용자가 붙여넣는 단위가 파일 하나**이므로
파일은 언제나 그 자체로 완전해야 한다.

| 파일 | 무엇 | 어디에 들어가는가 |
|---|---|---|
| `preamble.js` | 자기등록 · 전역 킬스위치 · 중복 설치 감지 | **모든** 스크립트 헤더 바로 뒤 |

`@@SLUG@@` `@@VERSION@@` `@@BASE@@` 는 반입 시 치환된다.

## preamble이 하는 세 가지

1. **전역 킬스위치** — 브라우저 콘솔에서 `localStorage.setItem('wap.kill','1')` 한 줄로 전 스크립트가 멈춘다.
   개별로 끄려면 `wap.kill.<slug>`. GM 저장소는 스크립트별로 격리되어 전역 킬이 불가능하므로 `localStorage`를 쓴다.
2. **중복 설치 감지** — 같은 스크립트가 두 벌 설치되면 두 번째가 스스로 멈추고 콘솔에 알린다.
   (`@name`을 바꾼 파일을 "새 스크립트로 설치"했을 때 실제로 일어나는 사고다.)
3. **자기등록** — `window.__WAP`와 `localStorage['wap.installed.<slug>']`에 자기 id·버전·기준커밋을 남긴다.
   이걸 읽으면 **지금 이 브라우저에서 실제로 도는 것**과 저장소를 대조할 수 있다.

## 확인이 필요한 것

`throw`로 실행을 중단한다. Tampermonkey에서 스크립트별 예외는 그 스크립트만 멈추고
호스트 페이지에 영향을 주지 않는 것이 정상 동작이지만, **`@run-at`·`@grant` 조합에 따라
다르게 동작하지 않는지는 회사 PC에서 한 번 확인해야 한다.**
확인 전까지는 위험이 가장 낮은 스크립트 하나에만 넣어보는 것이 안전하다.
