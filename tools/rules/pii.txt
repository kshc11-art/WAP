# 저장소에 들어가면 안 되는 값의 패턴 사전.
#   형식: <등급>\t<정규식>\t<설명>
#   등급: BLOCK = 커밋 차단 / WARN = 경고만 (리포트에 남고 커밋은 통과)
# 정규식은 Python re 문법. 파일은 \uXXXX 이스케이프를 디코딩한 뒤에도 한 번 더 검사된다.
#
# 이 파일을 고치는 것이 guard.py 코드를 고치는 것보다 우선이다.

# ── 자격증명 ────────────────────────────────────────────────
BLOCK	(?:Bearer|Basic)\s+[A-Za-z0-9._~+/=-]{16,}	인증 헤더 값
BLOCK	JSESSIONID\s*=\s*[A-Za-z0-9]{8,}	세션 ID
BLOCK	[Ss]et-[Cc]ookie\s*:	쿠키 헤더
BLOCK	(?:sk-ant-|ghp_|gho_|github_pat_)[A-Za-z0-9_-]{16,}	API 키/토큰
BLOCK	AKIA[0-9A-Z]{16}	AWS 액세스 키
BLOCK	(?i)(?:password|passwd|pwd)\s*[:=]\s*["'][^"']{4,}["']	하드코딩된 비밀번호

# ── 개인정보 ────────────────────────────────────────────────
BLOCK	[0-9]{6}-[1-4][0-9]{6}	주민등록번호 형식
BLOCK	[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]*\.re\.kr	연구기관 이메일 주소
BLOCK	[0-9]{5}-[가-힣]{2,4}(?![가-힣])	사번-이름 형식
BLOCK	01[016-9]-?[0-9]{3,4}-?[0-9]{4}	휴대전화번호

# ── 업무 실데이터 ───────────────────────────────────────────
# 관리번호 형식(예: 대문자1 + 숫자6 + 국가코드2). 익명 fixture는 TEST####로 쓴다.
BLOCK	\b[A-Z][0-9]{6}[A-Z]{2}\b	특허 관리번호 형식
WARN	\b[0-9]{2}-[0-9]{4}-[0-9]{6,7}\b	출원/등록번호 형식

# ── 회사 정책 확인이 필요한 것 (경고) ───────────────────────
# 내부 호스트명과 화면 ID는 스크립트의 @match·라우팅에 구조적으로 필요하다.
# 제거 대상이 아니라 "반출 가능한지 사람이 판단할 대상"이므로 WARN이다.
WARN	\b[a-z0-9-]+\.re\.kr\b	내부 호스트명
WARN	\bS_[A-Z]{3}_[0-9]{8}\b	내부 화면 ID
