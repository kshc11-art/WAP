# inbox/

**이 저장소에서 손대는 유일한 폴더다.**

AI 채팅에서 받은 `.user.js` 파일을 여기에 넣고 커밋한다. **파일명은 아무거나 상관없다.**
`팔레트_최종_v2 (1).user.js` 라도 된다 — 헤더를 보고 봇이 제자리에 놓는다.

```
inbox/ 에 넣고 커밋
      ↓
봇: slug 판정 → 헤더 정규화 → 프리앰블 주입 → 검사 → 색인 갱신
      ↓
scripts/<slug>.user.js 로 커밋 · 원본은 archive/ 에 보관 · inbox/ 는 비워짐
      ↓
그 파일을 Tampermonkey 편집기에서 덮어쓴다
```

## 봇이 절대 하지 않는 것

- **본문을 고치지 않는다.** 헤더 블록과 프리앰블만 손댄다.
- **병합하지 않는다.** 던진 것이 저장소보다 구버전이어도 그대로 받고 경고만 남긴다.
  (지금 회사 PC에서 도는 것이 그것일 수 있으므로.)
- **덮어쓰기로 충돌을 해결하지 않는다.** 한 번에 같은 slug가 둘 이상 들어오면
  전부 여기 남기고 실패시킨다. 파일이 조용히 사라지지 않게 하기 위해서다.

## 파일을 쪼개거나 합칠 때

먼저 `contracts/scripts.yaml`에 새 slug를 등록하고(합병이면 `supersedes:`) **그 다음에** AI에게 시킨다.
순서를 뒤집으면 돌아온 파일들이 같은 자리를 놓고 다툰다.
